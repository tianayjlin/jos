1. The purpose of having an individual function for each handler/exception is because it allows for appropriate of different events. Some interrupts require a graceful termination, some involve accessing and changing values, among differences. If multiple different interrupts were run, it allows for a clear, descriptive stack, because each interrupt handler is contained in its own stack frame, or scope.
